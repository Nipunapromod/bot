Setup checklist

Complete these once to bring your assistant online.

01
Connect Meta WhatsApp Cloud API

Create a Meta developer app, add WhatsApp, then add /api/webhook as the callback path. Subscribe to the messages field. Open Meta for Developers ↗

02
Set server environment variables

Add WhatsApp token, phone number ID, verify token and Meta app secret in Vercel → Project → Settings → Environment Variables. Never paste secrets into this page.

03
Enable natural-language AI

Set OPENAI_API_KEY and optionally OPENAI_MODEL. The bot understands normal questions, not only commands.

04
Enable internet search

Set TAVILY_API_KEY. Search is triggered for current, latest, news and lookup-style questions. Get a Tavily key ↗

05
Secure this dashboard

Set DASHBOARD_PASSWORD and a long random DASHBOARD_SESSION_SECRET. Redeploy after changing environment variables.

Meta controls WhatsApp account approval, opt-in, message templates and conversation-window rules. This dashboard does not bypass those requirements.
